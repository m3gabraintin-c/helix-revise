## VCE Units 3 & 4

### Logic & proof

#### Statements, quantifiers and counterexamples

**A1.** A. If n² is even, then n is even.
<!-- id: specialist-1-1-1 -->

Explanation: The converse of P ⇒ Q is Q ⇒ P, so the hypothesis and conclusion swap places.

**A2.** B. If x² ≤ 4, then x ≤ 2.
<!-- id: specialist-1-1-2 -->

Explanation: The contrapositive of P ⇒ Q is ¬Q ⇒ ¬P; the negation of x² > 4 is x² ≤ 4 and the negation of x > 2 is x ≤ 2.

**A3.** C. It rains and the match is not cancelled.
<!-- id: specialist-1-1-3 -->

Explanation: ¬(P ⇒ Q) is equivalent to P ∧ ¬Q: the implication fails only when the hypothesis holds and the conclusion does not.

**A4.** Converse: 'If a triangle is isosceles, then it is equilateral', which is false (e.g. sides 5, 5, 8). Contrapositive: 'If a triangle is not isosceles, then it is not equilateral', which is true.
<!-- id: specialist-1-1-4 -->

Explanation: The contrapositive always has the same truth value as the original statement, which is true. The converse needs its own check.

**A5.** D. ∃x ∈ R such that x² < 0
<!-- id: specialist-1-1-5 -->

Explanation: Negating swaps ∀ for ∃ and negates the predicate; the negation of x² ≥ 0 is x² < 0.

**A6.** A. ∀n ∈ N, n² ≠ 2n
<!-- id: specialist-1-1-6 -->

Explanation: The negation of 'there exists n with property P' is 'for every n, P fails'.

**A7.** B. p = 2
<!-- id: specialist-1-1-7 -->

Explanation: 2 is prime and even. 9 and 1 are not prime, and 3 is an odd prime, so it agrees with the claim.

**A8.** Take a = 3, b = 4: √(9 + 16) = 5, but a + b = 7, and 5 ≠ 7.
<!-- id: specialist-1-1-8 -->

Explanation: Any pair with a and b both non-zero works. Show both sides with numbers to earn the mark.

**A9.** C. n = 40
<!-- id: specialist-1-1-9 -->

Explanation: At n = 40 the expression is 1600 + 40 + 41 = 1681 = 41², which is composite. n = 1, 10 and 20 give the primes 43, 151 and 461.

**A10.** D. ∀x ∈ R ∃y ∈ R such that y > x
<!-- id: specialist-1-1-10 -->

Explanation: For any x, choose y = x + 1. The second option would need a largest real number, x = 0.5 gives 0.25 < 0.5, and no real number squares to −1.

**A11.** A. True
<!-- id: specialist-1-1-11 -->

Explanation: An implication is false only when P is true and Q is false. In every other case, including a false hypothesis, it is true.

**A12.** Take n = 3: 2³ = 8 and 3² = 9, and 8 < 9, so the statement is false. (n = 2 or n = 4 also work, since equality holds there.)
<!-- id: specialist-1-1-12 -->

Explanation: One explicit counterexample with both sides evaluated is enough to disprove a universal statement.

**A13.** B. P ⇒ Q and ¬Q ⇒ ¬P
<!-- id: specialist-1-1-13 -->

Explanation: A statement and its contrapositive always have the same truth value. The converse and the inverse are not equivalent to it, and P ∧ ¬Q is its negation.

**A14.** C. It is false; x = −3 is a counterexample.
<!-- id: specialist-1-1-14 -->

Explanation: A counterexample must make the hypothesis true and the conclusion false. x = −3 gives x² = 9 but x ≠ 3, while x = 0 and x = 9 do not satisfy x² = 9.

**A15.** D. The statement and its contrapositive are true; the converse is false.
<!-- id: specialist-1-1-15 -->

Explanation: Every square is a rectangle, so the statement and its contrapositive hold. A 2 × 5 rectangle is not a square, so the converse fails.

**A16.** Negation: '∀x ∈ R, x² + 1 ≠ 0'. The negation is true, because x² ≥ 0 gives x² + 1 ≥ 1 > 0 for every real x.
<!-- id: specialist-1-1-16 -->

Explanation: Swap ∃ for ∀ and negate the equation. Justify why no real solution exists.

**A17.** A. If n is divisible by 6, then n is even.
<!-- id: specialist-1-1-17 -->

Explanation: 'Q is necessary for P' means P ⇒ Q: whenever n is divisible by 6, n must be even.

**A18.** B. n is odd ⇔ n² is odd
<!-- id: specialist-1-1-18 -->

Explanation: An odd n gives an odd n², and an even n gives an even n². The others fail at n = −3, n = 2 and n = 2 respectively.

**A19.** C. At least one student in the class did not pass the SAC.
<!-- id: specialist-1-1-19 -->

Explanation: The negation of 'for all, P' is 'there exists one for which P fails', which is at least one student not passing.

**A20.** False. Counterexample: a = −3, b = 1. Here a < b, but a² = 9 > 1 = b².
<!-- id: specialist-1-1-20 -->

Explanation: The claim holds only for non-negative a and b. A negative a with a large magnitude breaks it.

**A21.** D. ∃x ∈ Z such that ∀y ∈ Z, x + y ≠ 0
<!-- id: specialist-1-1-21 -->

Explanation: Each quantifier flips (∀ becomes ∃ and ∃ becomes ∀) while the order stays the same, and the predicate is negated.

**A22.** A. x = 0.5
<!-- id: specialist-1-1-22 -->

Explanation: x = 0.5 > 0 but x³ = 0.125 < 0.5. x = −0.5 does not satisfy the hypothesis, and x = 2 and x = 3 satisfy the claim.

**A23.** B. If n is not a multiple of 4, then n is not a multiple of 2.
<!-- id: specialist-1-1-23 -->

Explanation: The inverse fails for n = 2, which is not a multiple of 4 but is a multiple of 2. The other three statements are always true.

**A24.** The first is true: for any x, take y = x + 1. The second is false: it says some y is greater than every real number, but taking x = y gives x < y false.
<!-- id: specialist-1-1-24 -->

Explanation: The order of quantifiers matters. In the first, y may depend on x; in the second, one y must work for all x.

**A25.** √2 and −√2 are both irrational, but √2 + (−√2) = 0, which is rational.
<!-- id: specialist-1-1-25 -->

Explanation: A single counterexample disproves the claim. Other valid pairs include (1 + √2) and (1 − √2), which sum to 2.

#### Direct proof and divisibility

**A26.** B. n² = 2(2k² + 2k) + 1
<!-- id: specialist-1-2-1 -->

Explanation: (2k + 1)² = 4k² + 4k + 1 = 2(2k² + 2k) + 1, which has the form 2m + 1 with m an integer.

**A27.** C. 2
<!-- id: specialist-1-2-2 -->

Explanation: One of two consecutive integers is even, so the product is even. n = 1 gives 2, which is not divisible by 3, 4 or 5.

**A28.** D. 6
<!-- id: specialist-1-2-3 -->

Explanation: Three consecutive integers include a multiple of 2 and a multiple of 3, so 6 divides the product. n = 1 gives 6, which rules out 4, 9 and 12.

**A29.** Let the integers be 2a and 2b, where a, b ∈ Z. Then 2a + 2b = 2(a + b), and a + b is an integer, so the sum is even.
<!-- id: specialist-1-2-4 -->

Explanation: Define the even integers with separate variables, and finish by writing the sum as 2 × (an integer).

**A30.** A. a | c
<!-- id: specialist-1-2-5 -->

Explanation: If b = am and c = bn, then c = a(mn), so a divides c. Divisibility is transitive.

**A31.** B. 3
<!-- id: specialist-1-2-6 -->

Explanation: (n − 1) + n + (n + 1) = 3n. 1 + 2 + 3 = 6 is not divisible by 9, and 2 + 3 + 4 = 9 is not divisible by 2 or 6.

**A32.** C. 2(m + n + 1)
<!-- id: specialist-1-2-7 -->

Explanation: (2m + 1) + (2n + 1) = 2m + 2n + 2 = 2(m + n + 1), which is 2 times an integer.

**A33.** n² + n = n(n + 1). Of the consecutive integers n and n + 1, one is even, so the product is even. (Or by cases: if n = 2k then n² + n = 2(2k² + k); if n = 2k + 1 then n² + n = 2(2k² + 3k + 1).)
<!-- id: specialist-1-2-8 -->

Explanation: Either the consecutive-integer argument or a full case analysis earns the marks. Both cases must be shown.

**A34.** D. (n − 1)n(n + 1)
<!-- id: specialist-1-2-9 -->

Explanation: n³ − n = n(n² − 1) = (n − 1)n(n + 1), which is a product of three consecutive integers and so is divisible by 6.

**A35.** A. n² − n is even.
<!-- id: specialist-1-2-10 -->

Explanation: n² − n = n(n − 1) is a product of consecutive integers, so it is even. The others fail at n = 1, n = 2 and n = 2 respectively.

**A36.** B. 1
<!-- id: specialist-1-2-11 -->

Explanation: n² = 9k² + 12k + 4 = 3(3k² + 4k + 1) + 1, so the remainder is 1 for every k.

**A37.** Since a | b and a | c, b = ak and c = am for some integers k, m. Then b + c = a(k + m), and k + m is an integer, so a | (b + c).
<!-- id: specialist-1-2-12 -->

Explanation: Use the definition of divisibility and different letters for the two multipliers.

**A38.** C. 0 or 1 only
<!-- id: specialist-1-2-13 -->

Explanation: (2k)² = 4k² leaves remainder 0, and (2k + 1)² = 4(k² + k) + 1 leaves remainder 1.

**A39.** D. 4
<!-- id: specialist-1-2-14 -->

Explanation: 5 ≡ 1 (mod 4), so 5ⁿ ≡ 1 and 5ⁿ − 1 ≡ 0 (mod 4). n = 1 gives 4, which is not divisible by 3, 6 or 8.

**A40.** A. 8
<!-- id: specialist-1-2-15 -->

Explanation: 2k(2k + 2) = 4k(k + 1), and k(k + 1) is even, so the product is a multiple of 8. 2 × 4 = 8 rules out 16, 6 and 12.

**A41.** Let n = 2k + 1. Then n² − 1 = 4k² + 4k = 4k(k + 1). k(k + 1) is a product of consecutive integers, so it is even: k(k + 1) = 2m. Hence n² − 1 = 8m.
<!-- id: specialist-1-2-16 -->

Explanation: The key step is that k(k + 1) is even, which supplies the extra factor of 2.

**A42.** B. 2a − 5b
<!-- id: specialist-1-2-17 -->

Explanation: With a = 3m and b = 3n, 2a − 5b = 3(2m − 5n). With a = b = 0, the other options give 1, 2 and 1, which are not multiples of 3.

**A43.** C. b ≠ 0 and d ≠ 0, so that bd ≠ 0
<!-- id: specialist-1-2-18 -->

Explanation: xy = ac/(bd), which is a ratio of integers. It is a valid rational number only if the denominator bd is non-zero.

**A44.** D. 10ᵏ − 1 is divisible by 9 for every integer k ≥ 0
<!-- id: specialist-1-2-19 -->

Explanation: Each digit dₖ contributes dₖ·10ᵏ = dₖ(10ᵏ − 1) + dₖ, so the number equals a multiple of 9 plus the digit sum.

**A45.** Let the integers be 2a + 1 and 2b + 1. Their product is 4ab + 2a + 2b + 1 = 2(2ab + a + b) + 1, which has the form 2m + 1 with m an integer, so it is odd.
<!-- id: specialist-1-2-20 -->

Explanation: Expand fully and write the result in the form 2m + 1.

**A46.** A. Let n = 4k for some integer k.
<!-- id: specialist-1-2-21 -->

Explanation: A direct proof starts from the hypothesis. Then n² = 16k², a multiple of 16.

**A47.** B. (√a − √b)² ≥ 0
<!-- id: specialist-1-2-22 -->

Explanation: (√a − √b)² = a − 2√(ab) + b ≥ 0 rearranges to a + b ≥ 2√(ab).

**A48.** C. odd
<!-- id: specialist-1-2-23 -->

Explanation: n² + n = n(n + 1) is even, so adding 1 gives an odd number. n = 4 gives 21, which is not prime, and n = 2 gives 7, which is not divisible by 3.

**A49.** Complete the square: x² − 6x + 10 = (x − 3)² + 1. Since (x − 3)² ≥ 0, the expression is at least 1, so it is greater than 0 for all real x.
<!-- id: specialist-1-2-24 -->

Explanation: Completing the square is the cleanest direct proof. A discriminant argument (Δ = 36 − 40 < 0 with a positive leading coefficient) is also accepted.

**A50.** n³ − n = (n − 1)n(n + 1), a product of three consecutive integers. One of them is a multiple of 2 and one is a multiple of 3. Since 2 and 3 are coprime, 6 divides the product.
<!-- id: specialist-1-2-25 -->

Explanation: State clearly why both 2 and 3 divide the product and why that gives divisibility by 6.

#### Contradiction and contrapositive proofs

**A51.** C. √2 = p/q, where p and q are integers with q ≠ 0 and no common factors
<!-- id: specialist-1-3-1 -->

Explanation: A proof by contradiction assumes the negation of the claim, that √2 is rational, written in lowest terms.

**A52.** D. p² is even, so p is even.
<!-- id: specialist-1-3-2 -->

Explanation: p² = 2q² is a multiple of 2, and an odd number has an odd square, so p must be even. That q is even only follows after substituting p = 2k.

**A53.** A. Both p and q turn out to be even, which contradicts p/q being in lowest terms.
<!-- id: specialist-1-3-3 -->

Explanation: After showing p = 2k, we get q² = 2k², so q is also even. Then 2 is a common factor, which contradicts the assumption.

**A54.** Assume √3 = p/q with p, q integers, q ≠ 0, in lowest terms. Then p² = 3q², so 3 | p² and, since 3 is prime, 3 | p. Write p = 3k: 9k² = 3q² gives q² = 3k², so 3 | q. Then 3 divides both p and q, which contradicts lowest terms. Hence √3 is irrational.
<!-- id: specialist-1-3-4 -->

Explanation: Marks for the lowest-terms assumption, the deduction that 3 | p, the deduction that 3 | q, and a clearly stated contradiction.

**A55.** B. If n is odd, then n² is odd.
<!-- id: specialist-1-3-5 -->

Explanation: The contrapositive of P ⇒ Q is ¬Q ⇒ ¬P. Here ¬Q is 'n is odd' and ¬P is 'n² is odd'.

**A56.** C. N = p₁p₂…pₖ + 1
<!-- id: specialist-1-3-6 -->

Explanation: N leaves remainder 1 when divided by each pᵢ, so no listed prime divides it.

**A57.** D. None of p₁, …, pₖ divides N, so N has a prime factor not in the list.
<!-- id: specialist-1-3-7 -->

Explanation: N > 1 has some prime factor, and that factor cannot be one of the pᵢ. N itself need not be prime.

**A58.** Contrapositive: if n is even, then n² is even. Let n = 2k. Then n² = 4k² = 2(2k²), which is even. Since the contrapositive is true, the original statement is true.
<!-- id: specialist-1-3-8 -->

Explanation: State the contrapositive explicitly before proving it.

**A59.** A. 2 × 3 × 5 × 7 × 11 × 13 + 1
<!-- id: specialist-1-3-9 -->

Explanation: 2 × 3 × 5 × 7 × 11 × 13 + 1 = 30031 = 59 × 509, which is composite. The others give the primes 7, 31 and 211.

**A60.** B. If n is even, then 3n + 2 is even.
<!-- id: specialist-1-3-10 -->

Explanation: Negate and swap: ¬(n odd) ⇒ ¬(3n + 2 odd). With n = 2k, 3n + 2 = 2(3k + 1), which is even.

**A61.** C. 2ᵖ is even but 3^q is odd.
<!-- id: specialist-1-3-11 -->

Explanation: For p ≥ 1, 2ᵖ is even, while every power of 3 is odd, so the two cannot be equal.

**A62.** Assume r is the smallest positive rational. Then r/2 is rational (a ratio of integers), positive, and r/2 < r. This contradicts r being the smallest, so no smallest positive rational exists.
<!-- id: specialist-1-3-12 -->

Explanation: Show that r/2 is rational, positive and smaller than r.

**A63.** D. N + 2 is even and greater than N, a contradiction.
<!-- id: specialist-1-3-13 -->

Explanation: N + 2 = 2(k + 1) is even and larger than N, which contradicts N being the largest.

**A64.** A. If x and y are both rational, then xy is rational.
<!-- id: specialist-1-3-14 -->

Explanation: This is the contrapositive. The negation of 'x or y irrational' is 'x and y both rational', and that case is easy to prove directly.

**A65.** B. n = 3k + 1 and n = 3k + 2
<!-- id: specialist-1-3-15 -->

Explanation: The contrapositive assumes n is not divisible by 3, which leaves remainders 1 and 2. Both cases give n² ≡ 1 (mod 3).

**A66.** Suppose 1/x is rational: 1/x = p/q with p, q integers and q ≠ 0. Since 1/x ≠ 0, p ≠ 0. Then x = q/p is rational, which contradicts x being irrational. So 1/x is irrational.
<!-- id: specialist-1-3-16 -->

Explanation: Note that p ≠ 0, so that dividing by p is valid.

**A67.** C. The left side equals 2(2a + 3b), which is even, but 1 is odd.
<!-- id: specialist-1-3-17 -->

Explanation: Assuming integer solutions exist leads to even = odd, which is impossible.

**A68.** D. 3 is prime and 3 | p², so 3 | p.
<!-- id: specialist-1-3-18 -->

Explanation: If a prime divides a product (here p × p), it divides one of the factors. That q is divisible by 3 is only shown afterwards.

**A69.** A. a + b ≥ 20, a < 10 and b < 10
<!-- id: specialist-1-3-19 -->

Explanation: Assume the hypothesis holds and the conclusion fails. The negation of 'a ≥ 10 or b ≥ 10' is 'a < 10 and b < 10'. This then gives a + b < 20, a contradiction.

**A70.** Since log₂(5) > 0, assume log₂(5) = p/q with p, q positive integers. Then 2^(p/q) = 5, so 2ᵖ = 5^q. The left side is even (p ≥ 1) and the right side is odd, a contradiction. Hence log₂(5) is irrational.
<!-- id: specialist-1-3-20 -->

Explanation: Justify that p and q can be taken as positive, and state the parity contradiction.

**A71.** B. √3 = r − 2 would be rational, which contradicts that √3 is irrational (rationals are closed under subtraction).
<!-- id: specialist-1-3-21 -->

Explanation: Rearranging gives √3 = r − 2. A difference of rationals is rational, so this contradicts the known irrationality of √3.

**A72.** C. Prove Q ⇒ P.
<!-- id: specialist-1-3-22 -->

Explanation: Q ⇒ P is the converse, which is not logically equivalent to P ⇒ Q. The other three are direct proof, contrapositive and contradiction.

**A73.** D. Assume no two share a birth month; then there are at most 12 students, a contradiction.
<!-- id: specialist-1-3-23 -->

Explanation: With 12 months and distinct months for everyone, there can be at most 12 students. This is the pigeonhole principle.

**A74.** Contrapositive: if a and b are both odd, then ab is odd. Let a = 2m + 1 and b = 2n + 1. Then ab = 4mn + 2m + 2n + 1 = 2(2mn + m + n) + 1, which is odd. Hence the original statement holds.
<!-- id: specialist-1-3-24 -->

Explanation: The negation of 'a even or b even' is 'a odd and b odd'. Check that this negation is correct.

**A75.** Assume such x and y exist. Then (x − y)(x + y) = 1. Since x + y ≥ 2 is a positive integer, the product of the integers x − y and x + y cannot be 1 (it would need x + y = 1). This is a contradiction.
<!-- id: specialist-1-3-25 -->

Explanation: Alternatively, both factors must equal 1, which gives y = 0, not positive. Either line of reasoning is accepted.

#### Mathematical induction

**A76.** D. Check n = 1: 2¹ = 2 and 1 + 1 = 2, so 2 ≥ 2 holds.
<!-- id: specialist-1-4-1 -->

Explanation: The base case is the smallest value in the domain, n = 1, and the inequality holds there with equality.

**A77.** A. P(k) ⇒ P(k + 1) for every k in the domain
<!-- id: specialist-1-4-2 -->

Explanation: Assuming the statement for n = k (the inductive hypothesis), we must deduce it for n = k + 1.

**A78.** B. k(k + 1)(2k + 1)/6 + (k + 1)²
<!-- id: specialist-1-4-3 -->

Explanation: The sum to k + 1 equals the sum to k plus the next term (k + 1)². Factoring out (k + 1)/6 leaves 2k² + 7k + 6 = (k + 2)(2k + 3).

**A79.** Base: n = 1, LHS = 1 = 1(2)/2. Assume 1 + … + k = k(k + 1)/2. Then 1 + … + k + (k + 1) = k(k + 1)/2 + (k + 1) = (k + 1)(k + 2)/2, which is the formula for n = k + 1. By induction, the result holds for all n ∈ N.
<!-- id: specialist-1-4-4 -->

Explanation: Marks for the base case, a clearly stated inductive hypothesis, the algebra to reach the n = k + 1 form, and a conclusion.

**A80.** C. 2k + 1
<!-- id: specialist-1-4-5 -->

Explanation: The (k + 1)th odd number is 2(k + 1) − 1 = 2k + 1, and k² + 2k + 1 = (k + 1)².

**A81.** D. 3(3ᵏ − 1) + 2
<!-- id: specialist-1-4-6 -->

Explanation: 3(3ᵏ − 1) + 2 = 3^(k+1) − 1. Both terms are even when 3ᵏ − 1 is even.

**A82.** A. 6(7m + 1)
<!-- id: specialist-1-4-7 -->

Explanation: 7^(k+1) − 1 = 7·7ᵏ − 1 = 7(6m + 1) − 1 = 42m + 6 = 6(7m + 1).

**A83.** Base: 5¹ − 1 = 4. Assume 5ᵏ − 1 = 4m. Then 5^(k+1) − 1 = 5·5ᵏ − 1 = 5(4m + 1) − 1 = 20m + 4 = 4(5m + 1), which is divisible by 4. Hence true for all n ∈ N.
<!-- id: specialist-1-4-8 -->

Explanation: Substitute 5ᵏ = 4m + 1 from the hypothesis and finish with 4 × (an integer).

**A84.** B. 5
<!-- id: specialist-1-4-9 -->

Explanation: 2⁴ = 16 = 4², so n = 4 fails the strict inequality, while 2⁵ = 32 > 25 and the inequality holds from then on. n = 1 works, but n = 2, 3 and 4 fail.

**A85.** C. 4
<!-- id: specialist-1-4-10 -->

Explanation: 3! = 6 < 8, but 4! = 24 > 16. The inequality then holds for all n ≥ 4 by induction.

**A86.** D. 17
<!-- id: specialist-1-4-11 -->

Explanation: a₂ = 3, a₃ = 5, a₄ = 9, a₅ = 17, which matches 2⁴ + 1 = 17.

**A87.** Base: n = 1 gives 1 = 1. Assume the sum to k is k²(k + 1)²/4. Then adding (k + 1)³ gives (k + 1)²[k² + 4(k + 1)]/4 = (k + 1)²(k + 2)²/4 = ((k + 1)(k + 2)/2)². Hence true for all n.
<!-- id: specialist-1-4-12 -->

Explanation: Factor out (k + 1)²/4 early, and recognise k² + 4k + 4 = (k + 2)².

**A88.** A. n(n + 1)(n + 2)/3
<!-- id: specialist-1-4-13 -->

Explanation: n = 1 gives 2 and n = 2 gives 8, which match. The other formulas fail at n = 1 or n = 2 (e.g. 2·3·5/3 = 10 ≠ 8).

**A89.** B. n/(n + 1)
<!-- id: specialist-1-4-14 -->

Explanation: n = 1 gives 1/2, and k/(k + 1) + 1/((k + 1)(k + 2)) = (k² + 2k + 1)/((k + 1)(k + 2)) = (k + 1)/(k + 2).

**A90.** C. Going from n = 1 to n = 2, because the two overlapping groups of k horses have no horse in common
<!-- id: specialist-1-4-15 -->

Explanation: The argument relies on overlapping groups sharing a horse. When k = 1, the groups {h₁} and {h₂} do not overlap, so P(1) ⇒ P(2) fails.

**A91.** Base: n = 2 gives 9 > 5. Assume 3ᵏ > 2k + 1 for some k ≥ 2. Then 3^(k+1) = 3·3ᵏ > 3(2k + 1) = 6k + 3 = (2k + 3) + 4k > 2k + 3 = 2(k + 1) + 1, since 4k > 0. Hence true for all n ≥ 2.
<!-- id: specialist-1-4-16 -->

Explanation: The step must reach 2(k + 1) + 1 and justify the final inequality (4k > 0).

**A92.** D. All integers n ≥ 3
<!-- id: specialist-1-4-17 -->

Explanation: The induction starts at the base case n = 3 and moves upward. Nothing is established for n = 1 or n = 2.

**A93.** A. 4(4ᵏ + 5) − 15
<!-- id: specialist-1-4-18 -->

Explanation: 4(4ᵏ + 5) − 15 = 4^(k+1) + 20 − 15 = 4^(k+1) + 5. Both terms are divisible by 3.

**A94.** B. 1023
<!-- id: specialist-1-4-19 -->

Explanation: The sum 1 + 2 + … + 2⁹ has 10 terms, so n = 10 and the total is 2¹⁰ − 1 = 1023.

**A95.** Base: 6 + 4 = 10 = 5 × 2. Assume 6ᵏ + 4 = 5m. Then 6^(k+1) + 4 = 6(6ᵏ + 4) − 20 = 30m − 20 = 5(6m − 4), which is divisible by 5. Hence true for all n ∈ N.
<!-- id: specialist-1-4-20 -->

Explanation: Writing 6^(k+1) + 4 in terms of 6ᵏ + 4 shows the inductive hypothesis being used.

**A96.** C. 5
<!-- id: specialist-1-4-21 -->

Explanation: 11 ≡ 1 (mod 5), so 11ⁿ − 6 ≡ 1 − 6 = −5 ≡ 0 (mod 5). n = 1 gives 5, which rules out 3, 7 and 10.

**A97.** D. cos A cos B − sin A sin B = cos(A + B) and sin A cos B + cos A sin B = sin(A + B)
<!-- id: specialist-1-4-22 -->

Explanation: Multiplying cos(kθ) + i sin(kθ) by cos θ + i sin θ gives real and imaginary parts that are the compound-angle expansions for (k + 1)θ.

**A98.** A. 1 + x > 0
<!-- id: specialist-1-4-23 -->

Explanation: Multiplying an inequality by a positive quantity keeps its direction, so x > −1 is needed. Then (1 + kx)(1 + x) = 1 + (k + 1)x + kx² ≥ 1 + (k + 1)x.

**A99.** Base: 2·3⁰ − 1 = 1 = a₁. Assume a_k = 2·3^(k−1) − 1. Then a_(k+1) = 3(2·3^(k−1) − 1) + 2 = 2·3ᵏ − 3 + 2 = 2·3ᵏ − 1, which is the formula for n = k + 1. Hence true for all n ∈ N.
